# AnimeVerse – Landing Page

Tugas 5 Praktikum – single page website dengan komponen carousel.

- **Nama:** [Angga Johanes Thesman]
- **NIM:** [535250016]

## Fitur

- Carousel (sliding banner) dengan efek fade dan auto-slide
- Navbar sticky dengan penanda menu aktif (scroll spy)
- Layout responsif (mobile, tablet, desktop) memakai React-Bootstrap
- Section: Home, Tentang, Koleksi, Kontak

## Menjalankan
1. npm install
2. npm run dev
3. Buka http://localhost:3000
